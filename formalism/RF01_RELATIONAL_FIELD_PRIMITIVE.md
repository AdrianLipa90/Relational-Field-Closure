# RF-01 — Relational Field Primitive

**Status:** OPEN_DERIVATION

The first derivation gate will construct a local field carrier directly from the pinned TIR + Secret-of-a-Half + IDT state variables.

Minimum required outputs:

1. a local state space or bundle,
2. a typed relational phase degree of freedom,
3. an admissible derivative/transport operator,
4. a local clock variable inherited from IDT rather than inserted as external coordinate time,
5. a rule for constructing scalar, one-form and rank-2 candidates without assuming Maxwell or Einstein equations.

The first exact question is whether the temporal/relational phase connection admits a spacetime one-form continuation whose curvature is generated by noncommuting local transport:

\[
A \in \Omega^1(M),
\qquad
F := dA.
\]

At RF-01 this is only a target type signature. The existence and physical identification of \(A\) remain to be derived.
